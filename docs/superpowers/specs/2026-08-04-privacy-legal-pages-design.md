## 목적

머니북가계부에 공개 개인정보처리방침과 이용약관을 제공하고, 회원가입 필수 동의와 선택형 분석 동의를 명확히 분리한다. 동의 화면만 추가하는 데 그치지 않고, 가입 시점의 문서 버전과 동의 일시를 보관해 동의 이력을 확인할 수 있게 한다.

본 문서는 구현 설계이며 법률 자문을 대체하지 않는다. 운영 전 최종 문구는 법률 전문가 검토를 권장한다.

## 처리 데이터와 외부 처리 경로

### 서비스가 처리하는 개인정보

| 목적 | 항목 |
| --- | --- |
| 가입·로그인·계정 관리 | 이름, 이메일, 암호화된 비밀번호, 인증 세션 정보, 동의 기록 |

| 투자 기록 | 종목명·종목코드·수량·매수가·매수일·계좌 유형·한도 |

외부 Pretendard CDN은 방문자의 네트워크 정보가 외부로 요청될 수 있으므로 제거하고, 같은 서체를 로컬 제공한다. 이를 통해 분석과 무관한 외부 전송을 늘리지 않는다.

## 페이지와 컴포넌트 구조

### 공개 문서 페이지

- `/legal/privacy`: 개인정보처리방침. 처리 목적, 항목, 보유 기간, 파기, 위탁·국외 처리, 제3자 제공 여부, 권리 행사, 자동수집, 보호책임자, 변경·시행일을 다룬다.
- `/legal/terms`: 이용약관. 서비스 정의, 자격, 계정 책임, 금지행위, 서비스 변경·중단, 탈퇴, 데이터 백업, 지식재산권, 투자정보 면책, 책임 제한, 준거법, 시행일을 다룬다.
- 두 페이지는 로그인 없이 공개하고, 검색엔진 접근을 허용한다.

문서 내용에 필요한 버전, 시행일, 운영자와 연락처는 `src/lib/legal/`의 한 모듈에서 관리한다. 회원가입과 문서 페이지 모두 이 상수를 사용한다.

### 상시 접근 경로

`LegalLinks` 재사용 컴포넌트를 만든다.

- 인트로 페이지 푸터에는 개인정보처리방침과 이용약관 링크를 추가한다.
- 앱 공통 푸터를 활성화해 로그인 후 화면에도 같은 링크를 제공한다.
- 인증 화면에서는 가입 폼의 동의 문구와 하단 링크로 문서에 접근하게 한다.
- 분석 동의가 가능한 모든 화면에는 `분석 설정` 링크를 제공한다.

## 회원가입 및 동의 이력

### 화면 동작

회원가입 폼에 다음 항목을 추가한다.

1. 전체 동의(편의 기능)
2. `[필수] 만 14세 이상입니다`
3. `[필수] 이용약관에 동의합니다`
4. `[필수] 개인정보 수집·이용에 동의합니다`

이용약관과 개인정보처리방침의 제목은 해당 공개 문서로 연결한다. 전체 동의는 세 필수 항목을 함께 변경하며, 개별 항목 변경 시 전체 동의 상태와 부분 선택 상태를 동기화한다.

필수 항목이 누락된 제출은 Supabase 요청 전에 차단한다. 첫 누락 항목에 오류 메시지를 표시하고 포커스를 이동해 키보드와 보조기기 사용자가 원인을 알 수 있게 한다.

### 서버 기록과 강제 규칙

`profiles`에 다음 열을 추가한다.

- `terms_version`, `terms_agreed_at`
- `privacy_version`, `privacy_agreed_at`
- `age_confirmed_at`

가입 요청은 현재 문서 버전과 필수 동의 플래그를 Supabase 사용자 메타데이터로 전달한다. `auth.users` 생성 트리거는 다음을 보장한다.

- 현재 버전의 약관·개인정보 동의 및 만 14세 이상 확인이 없으면 새 사용자 생성을 거부한다.
- 유효한 신규 가입이면 데이터베이스 서버 시각으로 동의 일시를 `profiles`에 기록한다.
- 기존 가입자의 프로필과 이메일 변경 흐름은 계속 동작한다.

이 방식은 화면 검증을 우회한 가입을 방지하면서, 실제 제출 시점의 동의 버전과 시각을 보관한다.

## 분석 동의

`AnalyticsConsent` 클라이언트 컴포넌트가 브라우저 저장소의 선택값을 관리한다.

- 최초 방문에는 하단 배너를 보이고 `선택 분석 동의`와 `거부`를 같은 비중으로 제공한다.
- 문서 링크와 분석 설정 진입점을 함께 제공한다.
- 동의 전에는 Google Analytics, Vercel Analytics, Speed Insights를 렌더링하거나 요청하지 않는다.
- 동의하면 세 도구를 로드한다.
- 거부 또는 철회하면 이후 로드를 중단하고, 가능한 범위에서 Google Analytics 쿠키를 삭제한다.
- 저장값이 없거나 손상되면 미동의 상태로 처리한다.

Vercel Analytics와 Speed Insights가 쿠키 없는 익명화 방식을 사용하더라도, 사용자가 선택형 분석을 일관되게 제어할 수 있도록 같은 동의 상태로 함께 제어한다.

## 약관의 투자정보 및 책임 제한

투자 화면의 시세·종목 정보는 정보 제공과 기록 보조 목적이며, 매수·매도 또는 특정 금융상품에 대한 권유가 아님을 명시한다. 시세의 정확성, 완전성, 실시간성 및 이용자의 투자 손익을 보장하지 않으며 투자 판단과 결과는 이용자에게 귀속된다.

서비스는 무료 개인 가계부로서 기능을 변경·중단할 수 있고, 이용자는 중요한 기록을 별도로 백업해야 한다. 다만 고의·중과실 또는 법률상 배제할 수 없는 책임을 면제하는 표현은 사용하지 않는다.

## 구현 범위와 비범위

포함:

- 법적 공개 페이지와 메타데이터
- 재사용 법적 링크와 공통 푸터
- 회원가입 필수 동의 UX와 프로필 동의 이력 마이그레이션
- 선택형 분석 동의 배너·설정·스크립트 지연 로드
- 외부 폰트 CDN 제거 또는 로컬 제공 전환
- 단위 테스트, 데스크톱·모바일 시각 검증, `HANDOFF.md` 갱신

포함하지 않음:

- 운영 Supabase 데이터베이스에 마이그레이션을 직접 적용하는 작업
- 배포 작업
- 별도 회원 탈퇴 UI
- 법률 자문 또는 법률 적합성 보증

## 검증 기준

1. 법적 페이지가 비로그인 상태에서 열리고 정확한 운영자·연락처·시행일을 표시한다.
2. 모든 필수 동의가 있어야만 회원가입 요청이 전송된다.
3. 신규 가입 시 동의 버전과 서버 기준 동의 시각이 `profiles`에 기록된다.
4. 기존 가입자는 새 트리거·열 추가 후에도 로그인과 프로필 생성 흐름이 유지된다.
5. 분석 도구는 미동의·거부·철회 상태에서 로드되지 않으며 동의한 경우에만 로드된다.
6. 데스크톱과 모바일에서 문서, 동의 영역, 분석 배너를 읽고 조작할 수 있다.
7. `npm test`, `npm run lint`, `npm run build`를 통과한다.

## 자체 검토

- **자리표시자:** 없음. 운영자, 이메일, 리전, 보유 기간, 시행일이 확정되어 있다.
- **일관성:** 선택 분석은 공개 페이지의 고지와 런타임 로드 제어가 같은 동의 상태를 사용한다. 가입 동의는 UI 검증과 DB 트리거 모두에서 강제한다.
- **범위:** 회원 탈퇴 UI와 운영 DB 반영·배포는 명시적으로 제외해 단일 구현 계획으로 관리한다.
- **모호성 해소:** Supabase의 주 데이터 저장 위치는 서울이며, Vercel과 Supabase 지원·운영 과정의 국외 처리는 정책에 별도 고지한다. 투자 개인 기록은 외부 시세 API로 전송하지 않는다.
