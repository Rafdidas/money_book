# Open Graph 대표 이미지 설계

## 목표

머니북가계부의 공개 페이지를 카카오톡, Slack, X 등에서 공유할 때 서비스의 목적을 즉시 이해할 수 있는 1200 x 630 대표 이미지를 제공한다.

## 선택한 방향

- 서비스 소개형 카드
- 브랜드 블루(`#3182f6`)를 배경의 중심 색으로 사용한다.
- 왼쪽에는 `머니북가계부` 로고, 핵심 문구 `돈의 흐름을 한눈에`, 보조 문구 `수입 · 지출 · 저축 · 투자`를 배치한다.
- 오른쪽에는 네 가지 돈의 흐름을 보여 주는 둥근 카드형 일러스트를 배치한다.
- 텍스트와 그래픽은 작은 공유 썸네일에서도 읽히도록 단순하게 유지한다.

## 구현

- 정적 PNG 파일을 `src/app/opengraph-image.png`에 둔다.
- Next.js App Router의 `opengraph-image` 파일 규칙을 사용해 전역 Open Graph 이미지 메타데이터를 자동 생성한다.
- 루트 `metadata`의 X/Twitter 카드는 `summary_large_image`로 변경해 같은 대표 이미지를 크게 표시한다.
- 기존 페이지별 제목과 설명은 유지한다.

## 검증

- 생성된 이미지는 정확히 1200 x 630 픽셀이어야 한다.
- 빌드 결과에서 Open Graph 및 X/Twitter 메타 태그가 대표 이미지 URL을 가리켜야 한다.
- 데스크톱과 모바일 브라우저 폭에서 공개 홈페이지의 기존 레이아웃이 영향을 받지 않아야 한다.
- `npm run lint` 및 `npm run build`를 실행한다.

## 범위 제외

- 로그인 이후 개인 데이터가 담긴 화면별 OG 이미지
- 페이지별 별도 OG 이미지
- 동적 렌더링 및 사용자 데이터 기반 이미지
