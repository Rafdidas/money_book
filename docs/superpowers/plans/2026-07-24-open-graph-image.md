# Open Graph 대표 이미지 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 공개 머니북가계부 페이지의 공유 미리보기에 서비스 소개형 대표 이미지를 표시한다.

**Architecture:** `src/app/opengraph-image.png`은 Next.js App Router의 파일 기반 메타데이터 규칙으로 Open Graph 태그를 자동 생성한다. 생성 스크립트는 1200 x 630 PNG의 시각 규칙을 재현 가능하게 유지하며, 루트 metadata는 X/Twitter가 동일한 이미지를 큰 카드로 표시하도록 이미지 URL을 명시한다.

**Tech Stack:** Next.js 16 App Router, TypeScript, Playwright Chromium screenshot, Vitest

## Global Constraints

- 사용자 노출 문구는 한국어를 사용한다.
- 대표 이미지는 정확히 1200 x 630 픽셀 PNG이며 8 MB보다 작아야 한다.
- 새 시각화 런타임 의존성을 추가하지 않는다.
- 공개 홈페이지의 기존 UI와 개인 데이터를 이미지에 포함하지 않는다.
- 의미 있는 단계마다 `HANDOFF.md`를 갱신한다.

**Interfaces:**

- Produces: `src/app/opengraph-image.png` (1200 x 630 PNG), `src/app/opengraph-image.alt.txt` (대체 텍스트).

- [ ] **Step 1: 실패하는 이미지 계약 테스트를 작성한다.**

```ts
import { readFile, stat } from "node:fs/promises";
import { describe, expect, it } from "vitest";

const imagePath = new URL("./opengraph-image.png", import.meta.url);

describe("Open Graph image", () => {
  it("is a 1200 by 630 PNG under the social-image size limit", async () => {
    const image = await readFile(imagePath);
    const size = await stat(imagePath);

    expect(image.subarray(1, 4).toString("ascii")).toBe("PNG");
    expect(image.readUInt32BE(16)).toBe(1200);
    expect(image.readUInt32BE(20)).toBe(630);
    expect(size.size).toBeLessThan(5 * 1024 * 1024);
  });
});
```

- [ ] **Step 2: 테스트가 이미지 파일 부재로 실패하는지 확인한다.**

Run: `npm run test -- src/app/opengraph-image.test.ts`

Expected: FAIL because `src/app/opengraph-image.png` does not exist.

- [ ] **Step 3: 1200 x 630 서비스 소개형 PNG를 생성하는 스크립트를 작성한다.**

```js
// scripts/generate-og-image.mjs
import { chromium } from "playwright";
import { writeFile } from "node:fs/promises";

const browser = await chromium.launch({ headless: true });
const page = await browser.newPage({ viewport: { width: 1200, height: 630 }, deviceScaleFactor: 1 });

await page.setContent(`<!doctype html><html><body>
  <main style="width:1200px;height:630px;background:#3182f6;color:white;display:flex;padding:72px;box-sizing:border-box;font-family:'Malgun Gothic',Arial,sans-serif">
    <section style="width:58%;display:flex;flex-direction:column;justify-content:center">
      <div style="font-size:34px;font-weight:800">머니북가계부</div>
      <div style="font-size:76px;font-weight:800;line-height:1.2;margin-top:32px">돈의 흐름을<br/>한눈에</div>
      <div style="font-size:30px;margin-top:28px;opacity:.9">수입 · 지출 · 저축 · 투자</div>
    </section>
    <aside aria-hidden="true" style="width:42%;display:flex;align-items:center;justify-content:center">...</aside>
  </main>
</body></html>`);
await page.screenshot({ path: "src/app/opengraph-image.png" });
await browser.close();
await writeFile("src/app/opengraph-image.alt.txt", "머니북가계부: 돈의 흐름을 한눈에, 수입·지출·저축·투자 관리");
```

The completed `aside` must use four white, rounded, non-overlapping cards labeled `수입`, `지출`, `저축`, `투자`, with a distinct simple finance glyph on each card. It must not include real account values or a dashboard screenshot.

- [ ] **Step 4: 생성기를 실행하고 이미지 계약 테스트가 통과하는지 확인한다.**

Run: `node scripts/generate-og-image.mjs; npm run test -- src/app/opengraph-image.test.ts`

Expected: PASS; the test reports a PNG width of `1200`, height of `630`, and a size below 5 MB.

- [ ] **Step 5: 결과 이미지를 육안 검토하고 커밋한다.**

Run: `git add scripts/generate-og-image.mjs src/app/opengraph-image.png src/app/opengraph-image.alt.txt src/app/opengraph-image.test.ts && git commit -m "feat: add open graph image asset"`

### Task 2: 전역 Open Graph와 X/Twitter 메타데이터 연결

**Files:**

- Test: `src/app/layout.test.ts`

**Interfaces:**
- Consumes: `/opengraph-image.png`, generated by Task 1.
- Produces: `metadata.twitter.card === "summary_large_image"` and `metadata.twitter.images === ["/opengraph-image.png"]`.

- [ ] **Step 1: 실패하는 메타데이터 계약 테스트를 작성한다.**

```ts
import { describe, expect, it } from "vitest";
import { metadata } from "./layout";

describe("root social metadata", () => {
  it("uses the Open Graph image as a large X/Twitter card", () => {
    expect(metadata.twitter).toMatchObject({
      card: "summary_large_image",
      images: ["/opengraph-image.png"],
    });
  });
});
```

- [ ] **Step 2: 테스트가 기존 summary 카드 때문에 실패하는지 확인한다.**

Run: `npm run test -- src/app/layout.test.ts`

Expected: FAIL because `metadata.twitter.card` is `summary` and no image is set.

- [ ] **Step 3: root metadata에서 같은 이미지를 X/Twitter에 연결한다.**

```ts

  card: "summary_large_image",
  title: siteTitle,
```

No `openGraph.images` field is needed: the root-level `opengraph-image.png` file convention generates the Open Graph image, type, dimensions, and alt tags automatically.

- [ ] **Step 4: 메타데이터 계약 테스트가 통과하는지 확인한다.**
